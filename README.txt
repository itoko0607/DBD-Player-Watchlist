DBD Player Watchlist v0.4.11

今回の変更点
・登録ユーザー一覧に、各記録の「編集」「削除」操作を追加。プロフィール一覧から対象記録を直接編集・削除できます。
・分類の説明表示を撤去し、その位置に「記録を追加」ボタンを配置。分類別カウンターによる分類選択は維持。
・ヘッダーのお気に入りボタンを撤去し、元の分類表示位置（メモ入力欄の上）へ移動。
・お気に入り（♡／♥）ボタンをヘッダーの元「記録を追加」位置へ移動。お気に入りONの場合は、記録の有無にかかわらずDBD記録ボタンが最優先で緑色になります。
・お気に入り状態は拡張機能のローカルストレージに保存され、プロフィール再表示後も維持されます。
・JSON形式のエクスポート／インポートを追加。登録ユーザー、各記録、お気に入り状態を保存・復元します。
・インポートは「統合」が初期設定。同じ記録IDがある場合はバックアップ側の内容で更新し、それ以外は追加します。「全置き換え」も選択できます。
・インポート前に確認を表示します。

既存データについて
・従来の保存キー dbdPlayerWatchlist_v020 と記録配列の形式を維持しています。既存の登録記録はそのまま引き継ぎます。
・お気に入り情報は別キー dbdPlayerWatchlist_favorites_v1 に保存します。
・旧バージョンの記録に保存されている分類情報は削除しません。
・Steam ID取得処理（/profiles/ と /id/）はv0.4.8相当の実装を維持しています。
・クラウド同期はありません。バックアップは手動でJSONファイルを保存してください。

バックアップの使い方
1. Steamプロフィール上で「DBD記録」を開きます。
2. 「データをエクスポート」でJSONファイルを保存します。
3. 復元時は「データをインポート」を押してJSONファイルを選びます。
4. 初期設定は「統合」です。バックアップの内容で現在のデータを置き換える場合は、インポート方法を「全置き換え」に変更してください。

更新方法（既存記録を引き継ぐため重要）
1. 現在の拡張機能フォルダを削除・移動しないでください。
2. ZIPを展開し、中の3ファイル（content.js / manifest.json / README.txt）を、現在読み込んでいる既存フォルダへコピーして上書きしてください。
3. Chromeの拡張機能管理画面で対象拡張機能の「再読み込み」を押してください。
4. Steamプロフィールを再読み込みしてください。

※同じ既存フォルダを使って更新してください。別フォルダから新規に読み込むと拡張機能IDが変わり、ローカル記録を引き継げない場合があります。
※ZIP内フォルダ名が変わっても、現在読み込んでいる既存フォルダ内のファイルを上書きしてください。
